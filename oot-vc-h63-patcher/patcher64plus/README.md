# Patcher64+ H63 integration

Target upstream: `Admentus64/Patcher64Plus-Tool`.

The integration extends Patcher64+ with a dedicated **VC emulator-only** patch entry for the H63 OoT Wii VC fixes.

## Files in the generated public overlay

```text
Patcher64Plus-H63-Integration/
├─ Patcher64Plus-H63-integration.patch
├─ README.md
├─ RELEASE-MANIFEST.json
└─ Files/
   └─ Games/
      └─ Ocarina of Time/
         └─ AppFile01/
            └─ oot-vc-usa-h63.ips
```

## Apply to a source checkout

From the root of a compatible `Patcher64Plus-Tool` checkout:

```bash
git apply --check /path/to/Patcher64Plus-H63-integration.patch
git apply /path/to/Patcher64Plus-H63-integration.patch
```

Then copy the overlay's `Files/` directory into the Patcher64+ root.

## New patch entry

`Wii VC H63 - Three-Point + Controller + Performance`

The entry is deliberately emulator-only:

- `vc_emulator_patch = AppFile01\\oot-vc-usa-h63.ips`
- accepted clean APP SHA-1: `763D4D3D0713E4D10E44540CCFA3255E19F28AF7`
- required patched APP SHA-1: `149CE67AE3FD25D80820E11C7EB4EB1886BE66CE`
- `vc_emulator_only = 1`
- Remove T64, Expand Memory, Remove Filter, and Remap Controls are forced off for this entry
- ROM/Redux/extension processing is disabled so the embedded N64 ROM is not silently changed

## Engine changes

The integration adds four fields understood by the Patcher64+ VC path:

- `vc_emulator_patch`
- `vc_emulator_hash`
- `vc_emulator_output_hash`
- `vc_emulator_only`

Before applying the IPS, Patcher64+ checks the extracted `00000001.app` SHA-1. It checks the H63 SHA-1 again after patching.

This design is derived from the earlier V3.3 integration that already passed JSON parsing, emulator-only option enforcement, PowerShell lexical validation, and IPS-to-APP reproduction tests.

## Payload generation

Do not substitute one of the old relinked v0.81/v0.82/v0.83 IPS files. H63 uses the stock-layout/Data7 hardware-safe executable layout and requires the new clean-stock-to-H63 IPS generated by `../tools/build_release.py`.
